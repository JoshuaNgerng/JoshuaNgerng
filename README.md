### 🤖 AI & Knowledge Graphs

**[Graphical RAG](https://github.com/JoshuaNgerng/Graphical_Rag_Draft)**

An experimental generic Graph RAG pipeline exploring how knowledge graphs can be constructed from unstructured documents without requiring a complete domain schema beforehand.

Current areas of exploration include:

* LLM-based entity and relationship extraction
* Entity resolution
* Relationship canonicalization and resolution
* Evidence-based relationship validation
* Neo4j knowledge graphs
* PostgreSQL processing checkpoints
* Vector embeddings and semantic retrieval
* FastAPI

The project is also an exploration of how automatically extracted knowledge could help discover and refine a domain-specific schema.

### 🖥️ Desktop Application Architecture

**[Frontend → Desktop Application Templates](https://github.com/JoshuaNgerng/Frontend_2_Desktop_app_template)**

An experimental template for packaging HTML-based prototypes into self-contained local desktop applications.

The project explores:

* PySide6
* Tauri / Rust
* SQLite
* YAML-driven configuration
* Request routing
* Worker/task separation
* Local resource management

The goal is to allow application-specific backend logic to be developed without repeatedly implementing the surrounding routing and resource-management infrastructure.
